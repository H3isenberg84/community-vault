# 🏦 community-vault

**Die Schatzkammer der VibecodingGermany-Community.**
Hier landen Snippets, Scripts, Configs, Prompts und alles, was zu klein für ein eigenes Repo ist — aber zu gut, um in irgendeinem Chat zu verschwinden.

> 🎙️ Entstanden aus der [VibecodingGermany](https://forum.vibecoding-germany.de)-Community und dem Mango Blau AI Podcast.

---

## 📁 Struktur

```
community-vault/
├── snippets/          # Kleine Code-Schnipsel (JS, Python, Shell, ...)
├── prompts/           # Prompt-Templates für Claude, GPT & Co.
├── configs/           # .cursorrules, .claude-settings, MCP-Configs, ...
├── scripts/           # Nützliche Automations-Scripts
├── templates/         # Projekt-Templates & Boilerplates
└── guides/            # Mini-Anleitungen & Cheatsheets
```

Jeder Ordner hat eine eigene `README.md` mit Index und kurzer Beschreibung der Inhalte.

## 🤝 Mitmachen

### Was rein darf

- **Snippets & Scripts:** Alles, was anderen Vibecodern das Leben leichter macht
- **Prompt-Templates:** Bewährte Prompts für Coding-Agents, mit kurzer Erklärung wann/warum
- **Configs:** Editor-Configs, Agent-Settings, alles was man sonst mühsam zusammensucht
- **Guides:** Kurze, fokussierte Anleitungen — kein Roman, eher Cheatsheet
- **Projekt-Links:** Eigene Repos in die Tabelle oben eintragen

### Was NICHT rein gehört

- Ganze Apps oder Tools → eigenes Repo anlegen (gerne unter der Org)
- Ungetesteter oder kaputter Code
- API-Keys, Tokens oder sonstige Secrets (komm schon, das wisst ihr)
- Copy-Paste aus geschlossenen Quellen ohne Lizenz

### So geht's

1. **Fork** dieses Repo
2. Leg deine Datei im passenden Ordner ab
3. Benenne sie sinnvoll: `beschreibung-was-es-tut.ext` (nicht `test123.py`)
4. Füge oben in der Datei einen kurzen Kommentar-Header ein:

```
# ============================================
# Name:        mein-cooles-script
# Beschreibung: Macht X damit Y einfacher wird
# Autor:       @dein-github-name
# Datum:       2026-03-18
# ============================================
```

5. Erstelle einen **Pull Request** mit kurzer Beschreibung
6. Ein Maintainer schaut drüber und merged

> Kein Git-Profi? Kein Stress. Poste es im [Forum](https://forum.vibecoding-germany.de) oder in der WhatsApp-Gruppe, dann hilft jemand beim Einstellen.
